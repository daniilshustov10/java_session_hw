# URL Shortener

## Описание
Консольное приложение для сокращения URL на **Java 21**. Позволяет создавать короткие ссылки, переходить по ним, управлять ссылками пользователя и автоматически удалять недоступные ссылки.

## Возможности

- Создание короткой ссылки из исходного URL.
- Генерация идентификатора пользователя (UUID) и переключение между пользователями.
- Просмотр и удаление собственных ссылок.
- Ограничение числа переходов по ссылке.
- Ограничение времени жизни ссылки (TTL).
- Периодическая очистка недоступных ссылок.
- Хранение данных в памяти приложения

## Технологии

- Java 21
- Maven
- Apache Commons Validator — проверка URL
- dotenv-java — чтение конфигурации из `.env`
- JUnit 5 и Mockito — unit-тесты
- Maven Checkstyle Plugin — проверка стиля кода
- JaCoCo — отчёт о покрытии и минимальный порог 50% по строкам
- GitHub Actions — CI

## Требования

- JDK 21
- Maven (или IntelliJ IDEA с поддержкой Maven)
- Git — для клонирования репозитория

## Установка и запуск

1. Клонируйте репозиторий:

   ```bash
   git clone https://github.com/daniilshustov10/java_session_hw.git
   cd java_session_hw
   ```

2. Создайте файл `.env` в корне проекта на основе `.env.example`:

   **Linux/macOS:**
   ```bash
   cp .env.example .env
   ```

   **Windows PowerShell:**
   ```powershell
   Copy-Item .env.example .env
   ```

3. Проверьте параметры конфигурации и при необходимости измените их.

4. Откройте проект в IntelliJ IDEA, дождитесь загрузки Maven-зависимостей и запустите класс `Main`.

   Для проверки сборки из терминала выполните:

   ```bash
   mvn clean verify
   ```

   > Команда `mvn clean verify` проверяет и собирает проект, но сама по себе не запускает интерактивное консольное приложение.

## Конфигурация

Пример `.env`:

```dotenv
LINK_NAVIGATION_LIMIT=5
LINK_LIFETIME_MINUTES=15
CLEANUP_UNAVAILABLE_LINKS_INTERVAL_HOURS=1
```

| Переменная | Описание | Значение в примере |
|---|---|---|
| `LINK_NAVIGATION_LIMIT` | Максимальное число переходов по ссылке | `5` |
| `LINK_LIFETIME_MINUTES` | Время жизни ссылки в минутах | `15` |
| `CLEANUP_UNAVAILABLE_LINKS_INTERVAL_HOURS` | Интервал фоновой очистки в часах | `1` |

## Работа с приложением

После запуска откроется интерактивное меню. В нём можно:

1. Создать короткую ссылку.
2. Перейти по короткой ссылке (исходный URL откроется через системный браузер).
3. Просмотреть свои ссылки.
4. Удалить ссылку.
5. Создать пользователя или переключиться на существующего по UUID.
0. Завершить работу.

При первом создании ссылки приложение автоматически создаёт пользователя. Сохраните его UUID, если планируете переключаться между пользователями в рамках текущего запуска.

## Тестирование

Запустить тесты:

```bash
mvn test
```

При `verify` Maven выполняет Checkstyle, компиляцию, unit-тесты и проверку покрытия JaCoCo. В `pom.xml` задан минимальный порог **50% покрытия строк кода по проекту в целом**.

После выполнения тестов и формирования отчёта JaCoCo откройте:

```text
target/site/jacoco/index.html
```

## CI

В репозитории настроен GitHub Actions workflow, который запускает Maven-проверки при событиях GitHub, указанных в `.github/workflows/`. Статус сборок можно посмотреть во вкладке [Actions](https://github.com/daniilshustov10/java_session_hw/actions).
